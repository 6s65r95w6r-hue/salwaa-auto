# Liste d'épisodes Salwaa (histoires vraies tirées de hadiths authentiques)

**Statuts :** `todo` / `done` / `bloqué`.
**Avertissement :** les références ci-dessous sont des **pistes de travail écrites de mémoire. Aucune n'est vérifiée.** L'agent doit, pour chaque épisode, vérifier le texte arabe, le numéro et le grade sur deux sources (sunnah.com + dorar.net, voir §4 de CLAUDE.md) avant d'utiliser quoi que ce soit. Si la vérification échoue : statut `bloqué`, épisode suivant.
**Histoires à refuser :** tout récit sans chaîne authentique qui circule sur les réseaux (par exemple la vieille femme qui jetait des ordures sur le Prophète ﷺ).

Règles de choix : voir §1b. Plus petit numéro `todo` qui respecte les règles (pas deux fois le même thème d'affilée, « téléphone vs prière » au plus 1 vidéo sur 5, jamais le même hadith avant 90 jours).
